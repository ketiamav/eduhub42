# EduHub Ecosystem Builder

Build a modern, professional, fully responsive website for EduHub42, an Education Development Enterprise — not a basic tutoring website. It should feel like an established, growing education ecosystem: clean, premium, trustworthy, youthful, and purpose-driven. Avoid anything that reads as a generic AI-generated template.

Positioning: EduHub42 is bigger than tutoring. It supports learners across academic development, education access, and career readiness. Never present it as "just a tutoring company" — it is an Education Development Enterprise building an integrated ecosystem.

Logo & Header Treatment (important — custom direction)
Use the actual EduHub42 logo file I upload. Do not recreate, redesign, or reinterpret the logo.
The logo must not sit in a boxed/contained navbar the way most sites do. Instead, treat the top of the site like a LinkedIn-style banner: a full-width header band (gradient or subtle brand-colour background in deep navy/teal) that the logo sits within and blends into naturally, spanning across the top of the page rather than being confined to a small corner logo lockup.
As the user scrolls, transition smoothly into a slimmer, standard sticky navigation bar (logo shrinks down into a normal nav logo at that point) — but the initial impression on page load should feel like a branded banner, not a plain white nav with a logo in the corner.
Never place the logo inside a hard-edged coloured box. It should feel like it's part of the background, not stamped on top of it.
Colour Palette
Deep navy blue (primary)
Teal / turquoise (secondary/accent)
Very light grey (backgrounds/section separation)
Subtle navy → teal gradients where appropriate (used sparingly, not on every section)
White space should do a lot of the work — avoid gradients or colour everywhere
Design Style

Modern, corporate, professional, premium, youthful, approachable, trustworthy, purpose-driven, technology-enabled. Use strong typography, generous white space, rounded cards, subtle shadows, clean section layouts, smooth transitions, subtle hover states.

Avoid: excessive animation, overly bright colours, clutter, large blocks of text, generic stock-photo layouts, over-rounded elements, "AI-generated" visual clichés, gradients on every section, turning every section into a grid of cards.

Style it in WhatsApp's signature green (
#25D366 or equivalent), with a white WhatsApp icon, rounded/pill shape, subtle shadow, and a light hover/pulse animation to draw attention without being obnoxious.
Clicking it opens the WhatsApp channel link in a new tab: [WHATSAPP_CHANNEL_LINK] → https://whatsapp.com/channel/0029VbCIRQhFsn0gJ1MDxo1y
